# UpPear attribution notice

UpPear is derived from Pearcleaner, originally developed by Alin Lupascu
(alienator88) and contributors.

Original project: https://github.com/alienator88/Pearcleaner
Source baseline: Pearcleaner 5.4.3
Upstream commit: c52695d90c43f60abd5cd10c363f2e122c65f191

UpPear retains and adapts Pearcleaner's App Store lookup and region fallback,
Sparkle update checker and candidate selection, Homebrew installed metadata
and version comparison logic, and application source detection. Modified
source files carry notices; docs/PROVENANCE.md lists their origins and changes.

UpPear adds a dedicated native SwiftUI interface, explicit check results,
channel-safe handoffs, bounded checking, menu bar and local scheduling,
notification opt-in, tests, and resumable project documentation.

Pearcleaner uninstall, cleanup, privileged helper, Finder extension, Sentinel,
and direct App Store/Sparkle installers are excluded from UpPear 1.0.
