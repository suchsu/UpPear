# UpPear 1.0.0

作者：suchsu。

原生 macOS 更新管理器，基于 Pearcleaner 5.4.3 的既有更新代码，支持 App Store 中国区优先及地区回退、Homebrew Cask/Formula 和 Sparkle。

App Store 打开官方商店，Sparkle 打开原应用；Homebrew 单项升级需确认。原生 SwiftUI 界面、菜单栏、设置和用户定稿图标，关于页注明作者与原项目来源。

需要 Apple Silicon / macOS 27.0 或更新。DMG 使用作者提供的 1.0.0 App 原样封装，签名类型为 ad-hoc。打开 DMG 后将 UpPear.app 拖入 Applications。

应用代码、Xcode 工程、测试、依赖和构建脚本公开；私人交接日志、详细软件清单及本地历史包不上传。源码包 SOURCE_REVISION 对应原始构建代码提交。

保留 Pearcleaner 的 Apache 2.0 + Commons Clause；完整许可随 App 和 DMG 分发。此版本不含 MAU、清理、卸载或 UpPear 特权 Helper。
